# Методология расчётов (ядро v0.1.0)

Все показатели — детерминированные геометрические расчёты. AI их не вычисляет и не изменяет.

## Обозначения

| Символ | Модель | Роль файла |
|---|---|---|
| D | Проектный солид камеры | `stope_design` |
| O | Солид кондиционной руды | `orebody` |
| L | Солид некондиционной руды (L := L − O) | `low_grade` |
| S | Солид выработанного пространства по маркшейдерской съёмке | `survey_solid` |
| BM | Блочная модель: XC, YC, ZC, XINC, YINC, ZINC, DENSITY, AU, AG, CU, ZN | `block_model` |

## Геометрия

* Булевы операции (∩, −, ∪) — библиотека **manifold3d** (робастные операции над замкнутыми многообразными сетками, двойная точность).
* Объём — точная сумма знаковых объёмов тетраэдров для заданной триангуляции, без вокселизации.
* Перед расчётом все модели переносятся в локальное начало координат (целая часть минимума габарита проекта), чтобы не терять точность на UTM-координатах. Объёмы от переноса не зависят.
* Упрощение геометрии для 3D-просмотра (Этап 2) на расчёт не влияет: расчёт всегда идёт по исходным файлам, целостность которых проверяется по sha256.

## Ore Loss (ТЗ п. 6)

| Показатель | Формула |
|---|---|
| V_plan_ore | Volume(D ∩ O) |
| V_extracted_ore | Volume(D ∩ O ∩ S) |
| V_loss | V_plan_ore − V_extracted_ore; контроль: Volume((D ∩ O) − S), невязка выводится |
| Ore Loss, % | V_loss / V_plan_ore × 100 |
| T_loss | Σ Volume(Loss ∩ Block_i) × ρ_i; без блочной модели V_loss × ρ_ore |
| M_loss | Σ T_i × G_i / 1000 (г/т → кг: Au, Ag); Σ T_i × G_i / 100 (% → т: Cu, Zn, Pb) |

Дополнительно: руда, добытая за проектным контуром, Volume((S ∩ O) − D).

## Dilution (ТЗ п. 7)

Фактическая выемка S делится на непересекающиеся категории: руда (S ∩ O), некондиция (S ∩ L), пустая порода (S − O − L внутри блочной модели) и «не определено» (S − O − L вне блочной модели). Баланс V_actual = V_ore + V_low_grade + V_waste + V_undefined проверяется.

| Показатель | Формула |
|---|---|
| Dilution (объём), % | V_waste / V_actual × 100 |
| Dilution (тоннаж), % | T_waste / (T_ore + T_waste) × 100 |
| Planned dilution (проект), % | Volume(D − O − L) / Volume(D) × 100 |
| Planned dilution (факт), % | Volume((S ∩ D) − O − L) / V_actual × 100 |
| Unplanned dilution, % | Volume((S − D) − O − L) / V_actual × 100 |
| Total dilution, % | Planned (факт) + Unplanned |

Некондиционная руда показывается отдельно и в разубоживание по пустой породе не входит.

## Зоны камеры (кровля, почва, стенки)

Объём режется точными плоскими сечениями на ячейки (по умолчанию 2 м). Каждая ячейка относится к зоне по внешней нормали ближайшей грани опорной поверхности, то есть того солида, за пределами которого лежит объём:

* потери и недобор → контур съёмки S;
* перебор → проектный контур D;
* пустая порода → контур руды O ∪ L.

Нормаль круче 45° к горизонту даёт кровлю или почву, остальные нормали дают стенку по азимуту (С/В/Ю/З). Сумма зон равна полному объёму. Профиль по высоте строится точными горизонтальными сечениями.

## Ограничения (ТЗ п. 18)

Геометрический перебор не равен пустой породе, доставленной на фабрику. Геометрическая недоотработка не равна окончательным потерям запасов. Производственные потери и разубоживание считаются отдельно по производственным данным (Этап 3).

## Контрольные примеры (backend/tests)

* Эталонная камера SYN-01 из параллелепипедов. Все объёмы известны аналитически, совпадение до 1e-9.
* Цилиндр (64-угольная призма) против точной площади многоугольника.
* Инвариантность к переносу в UTM и к повороту на 33°.
* Блочная модель с переменной плотностью и содержаниями по слоям: тоннаж и металл против ручного расчёта.
* Неправильные тела (деформированные сферы, повёрнутое рудное тело): булевы операции против **независимого метода** — интегрирования по вертикальным колонкам с трассировкой лучей. Расхождение < 0,15 %.
