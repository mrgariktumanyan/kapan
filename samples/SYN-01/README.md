# Тестовая камера SYN-01

Синтетическая камера, у которой все объёмы известны заранее. Координаты в стиле UTM: X ≈ 500 000, Y ≈ 4 300 000, Z ≈ 700.

| Файл | Категория → назначение |
|---|---|
| `SYN-01_design.dxf` (или `.stl`) | B. Проект камеры → Проектный солид камеры |
| `SYN-01_orebody.dxf` (или `.stl`) | A. Геологическая модель → Рудное тело (кондиция) |
| `SYN-01_survey.dxf` (или `.stl`) | C. Маркшейдерская съёмка → Солид выработанного пространства |
| `SYN-01_blockmodel.csv` (необязательно) | A. Геологическая модель → Блочная модель |

Геометрия (размеры в метрах):
* проект 20 × 10 × 30 = 6 000 м³;
* рудное тело мощностью 8 м, проект шире руды на 1 м с каждой стороны;
* съёмка: недобор 3 м по почве, перебор 1 м по южной стенке.
